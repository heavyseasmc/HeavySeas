# data/ —— 规则数值

本目录存放游戏的规则数值配置：角色阵容、物资牌配比、航海牌、天候牌。

## 权属声明

> 本目录为游戏规则数值配置。规则、数值与平衡关系属于游戏机制，不受著作权保护，
> **本项目对本目录内容不主张任何权利。**

## 为什么数值不写死在代码里

四个理由，每一条单独都足够：

1. **调参不必重新编译** —— 平衡需要成百上千局模拟来收敛。
2. **房主可自定义阵容** —— 6/7/8 人三套预设本来就是数据，不是逻辑。
3. **权属边界可见** —— 就是上面那条声明，它需要一个能被单独指认的目录。
4. **规则引擎保持纯粹** —— 引擎只认 schema，不认具体数字。

## schema 版本

每个 JSON 顶层都带 `schema_version`。**改动字段含义时必须递增**，并在
`engine/src/main/java/io/github/heavyseasmc/engine/data/` 下保留对旧版本的读取路径，
直到确认没有存档依赖它。

数值可以随便改，schema 不行——前者是平衡，后者是兼容性。
