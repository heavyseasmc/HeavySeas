# 先看样件区

样件区是一排开口的小间，一间一种拼好的标准组合。在测试世界里用这条指令摆到船边：

开口朝南。站在南边往北看，从西往东依次是：白漆护墙板与描金框 · 桃花心木主景 · 整扇窗 · 玻璃双开门 · 浴室 · 舷窗拼大 · 地毯 · 天花与梁 · 灯 · 楼梯与栏杆 · 家具。下面各章按这个次序讲。

# 物品栏与装修锤

## 物品栏

本模组的方块按用途分八页：结构材料 · 线脚装饰 · 门窗玻璃 · 楼梯栏杆 · 灯 · 家具 · 甲板设备 · 玩法道具；救生艇另一页。页内按材料成套排。

搜索认常用叫法：搜「踢脚线」「墙裙」「吊顶」「顶角线」都找得到对应的件。

## 装修锤

装修锤管「放下以后再改」。拿着它右键一格，那一格（多格的整件一起）换成下一种形态，快捷栏上方报新形态的名字。它管这几样：

- 整扇窗的窗台：屋里 → 屋外 → 两边 → 没有
- 墙面类方块的背面：饰面 ↔ 外墙白
- 桃花心木顶帽：普通 ↔ 高檐；桃花心木壁柱：左半根 → 居中 → 右半根
- 吸顶灯：一格 → 两格（东西）→ 两格（南北）→ 四格；旁边放不下的那一种跳过
- 格架的常春藤、躺椅的毯、肖像画的人、吊艇架的艇在哪一边

潜行右键舷窗：锁成单格 ↔ 恢复自动拼大。

# 材料

- **白漆外墙**：方块 · 台阶 · 半砖。船外的墙、甲板室、舷墙。
- **白漆内墙**与**白漆护墙板**：屋里的墙。护墙板是墙脚那一排。
- **桃花心木**：墙板 · 护墙板 · 台阶 · 楼梯 · 壁柱 · 顶帽。头等公共间、楼梯厅。
- **柚木甲板**：地板，放的时候板条顺着你面朝的方向。台阶与楼梯给露天甲板用。
- **船壳板**五色（黑 · 白 · 红 · 水线 · 黄褐）：方块 · 台阶 · 半砖。板缝按世界坐标自己排，拼多大都对得上。
- **白漆平顶**与**奶油色平顶**：天花。平顶的半砖就是吊顶、半格高的梁。
- **白瓷砖墙**与**马赛克地砖**：浴室、游泳池。

墙面类方块（内墙、护墙板、大框、桃花心木墙板）四个侧面都画了饰面，怎么放都一样；只有背后朝船外时，用装修锤把背面切成外墙白。

# 墙与线脚

一面讲究的墙从下往上是：踢脚 · 护墙板 · 腰线 · 大框 · 素面 · 檐口。

- **踢脚**、**腰线**、**檐口**都贴在墙前那一格。挨着的同一种自己连成一条，转角自己接。
- **壁柱**立在墙前。腰线碰到壁柱会从壁柱上穿过去；壁柱顶上挨着凸出檐口时，自己长出柱头托住它。
- **大框**（白 · 描金细线 · 金饰条宽框 · 桃花心木 · 桃花心木描金）是整块墙，一格一块，相邻的自己连成一整幅。
- **门套**贴在门洞两侧与上方。

这些都是看邻居自己接的，放下就对；不用右键叠层。

# 门窗

## 整扇窗

整扇窗有九种尺寸（宽 1–3 × 高 1–3），一件就是一整扇。窗台默认在你站的那一侧，玻璃跟着窗台走；用装修锤轮换窗台。船上的窗一律屋外窗台。

## 舷窗

同一种舷窗、同一个朝向排成完整的正方形，就自己拼成一个大圆：2 × 2、3 × 3、4 × 4。拼不成正方形的各自是小舷窗；拆掉一格，那一组散开重拼。

想留单个的，潜行时用装修锤点一下锁住。

## 门

客房门是单扇。玻璃双开门两扇并排放，右键一扇，两扇一起开。

# 地面与天花

## 地毯

地毯是地板的一层表面：拿地毯右键一格柚木甲板，那一格就铺上了；用剪刀右键揭掉。地毯的花边自己看四周收边，不用挑边角件。家具放在铺了毯的地板上，正好贴着毯面。

## 天花

平顶整片铺。描金白漆天花梁挂在平顶下面半格：两个方向都有梁的那一格自己接成十字，只有一个方向就顺着它转过去。描金檐口与凸出檐口一样拐角，只和同一种接。

# 灯

- **吸顶灯**：一盏挂在一格正中。屋子是双数宽时，用装修锤切成两格或四格，灯就骑在缝上居中。
- **黄铜吊灯**、**水晶大吊灯**：挂在大屋正中。
- **壁灯**贴墙；**落地灯**、**甲板灯柱**立在地上。

右键灯开关。

# 楼梯与栏杆

- 楼梯有铺毯桃花心木、桃花心木、柚木、白漆、船壳板几种。
- **铸铁栏杆**像栅栏一样接邻居，也接墙与实心方块。拐角与端头自己立起步柱。
- 楼梯旁用**铸铁楼梯栏杆**（斜的）；最下一级旁边立一根**黄铜灯起步柱**。
- 楼梯口四周的平台边上立一圈铸铁栏杆；楼板挨着洞口的那一面贴**洞口收口**。

# 家具

- 跨几格的家具（沙发、写字台、床、大圆桌、两格高的灯）一件物品摆出整件，空间不够就摆不下；拆掉任何一格整件一起没。
- 柜子右键开合；有座位的件（沙发、椅子、躺椅、床沿）右键坐下。
- 贴墙的家具（衣柜、盥洗台、书柜）背贴墙放，正面朝屋里。
- 浴室件（淋浴、马桶、洗脸盆）背贴墙；毛巾架挂在墙上。
