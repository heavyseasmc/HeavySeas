# 怒海狂涛 · Heavy Seas

> 八个人，一条小艇，四十升水。

1912 年 4 月，北辰号沉没。你在一艘救生艇上醒来。

你的身份人人可见，但你手里有一张谁也不能看的**喜爱**和一张**憎恨**。
体型既是你的血量，也是你的战斗力，还是别人恨你时你死掉值多少分——
**壮的人难杀，但不值钱**。

水不够喝，救生圈只有一个，而船尾的舵手决定今天谁会落水。

当第四只海鸥出现，雾散开，陆地在望——游戏当场结束，不管你是死是活。
死了也能赢：你的仇人淹死了，你爱的人活着，你怀里的珠宝还在。

## 这是什么

Minecraft / Fabric 的 6–8 人谈判游戏。一局 40–60 分钟。

你本人坐在一艘真的救生艇上，从船头到船尾的座位就是发言顺序、物资分配顺序
和舵手权本身。

- **真座位** —— 换座位就是真的挪位置，全艇一眼看懂谁在抢舵
- **真落水** —— 被扔进海里，游回来
- **真海鸥** —— 天上盘旋，抬头就能数
- **不隔离语音** —— 昏迷的人也要能喊"谁有水救我一口"

## 状态

开发中。当前进度：**M1 —— Fabric 模组骨架**（目标 Minecraft 1.21.1）。

规则引擎（`engine/`）不依赖 Minecraft，单测不需要启动游戏：

```bash
./gradlew :engine:test
```

模组（`mod/`）：

```bash
./gradlew :mod:build        # 产物在 mod/build/libs/
./gradlew :mod:runServer    # 开发环境起服；首次需先在 mod/run/eula.txt 写入 eula=true
```
